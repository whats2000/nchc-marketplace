# NCHC Marketplace

Claude Code plugin marketplace for TWCC / NCHC HPC cluster skills.

## Installation

```bash
/plugin marketplace add NCHC-bio/nchc-marketplace
/plugin install nchc-cluster-skills@nchc-marketplace
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| `nchc-cluster-skills` | SLURM job submission, GPU allocation, pricing, and post-job review for NCHC clusters |
